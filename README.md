# Creative Web Design

A responsive Vietnamese website template practice project featuring an image-led hero, sticky navigation, service cards, hover transitions, and a two-column footer.

## Run

Open `index.html` in a modern browser. No build tools or JavaScript dependencies are required.

## Project structure

```text
index.html
css/style.css
images/banner.svg
images/service1.svg
images/service2.svg
images/service3.svg
```

The artwork is stored locally as SVG files so the page works without remote image services.
